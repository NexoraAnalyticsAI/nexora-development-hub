# Contributing to Nexora Analytics AI

Thank you for your interest in contributing to Nexora Analytics AI.

## How to Contribute

1. Create a new branch for your changes.
2. Make your changes clearly and responsibly.
3. Test your changes before submitting.
4. Create a Pull Request.
5. Explain what you changed and why.

## Code Quality

- Keep code clean and readable.
- Do not commit passwords, API keys, or private information.
- Follow the existing project structure.
- Add documentation when necessary.

## Pull Requests

Please provide a clear title and description for every Pull Request.

Thank you for helping us build Nexora Analytics AI! 🚀
